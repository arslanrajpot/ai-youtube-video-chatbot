# YouTube Talker — AI Video Content Analyst

An AI-powered web application that lets users chat with any YouTube video in natural language, turning long videos into instant, searchable answers instead of requiring a full watch-through.

## Overview

Given a YouTube video URL, the app pulls the video's transcript (or transcribes the audio directly with OpenAI Whisper when no transcript is available), indexes the content with vector embeddings, and lets users ask free-form questions. Answers are generated by an LLM grounded in the retrieved transcript chunks, so responses stay accurate and tied to what's actually said in the video.

## Key Features

Works with any YouTube video, with or without existing transcripts. AI audio transcription via OpenAI Whisper, supporting 99+ languages. Fast, context-aware responses powered by Groq's Llama 3.1 with HuggingFace embeddings for retrieval. An automatic fallback system between AI providers for reliability. Full multi-language support, so videos in any language can be queried in natural language.

## Tech Stack

Backend: Flask (Python). AI Transcription: OpenAI Whisper. LLM: Groq (Llama 3.1). Embeddings: HuggingFace Sentence Transformers. Vector Database: FAISS. Frontend: Bootstrap and JavaScript.

## Deployment

This project is deployed on Render.com.

## Environment Variables

`GROQ_API_KEY` (required) — your Groq API key for LLM responses.
`GOOGLE_API_KEY` (optional) — Google Gemini API key, used as an alternate provider.

## Getting Started

```bash
pip install -r requirements.txt
echo "GROQ_API_KEY=your_key_here" > .env
python app.py
```

## Usage

Submit a YouTube video URL, then wait roughly 30 to 60 seconds while the video is processed and transcribed. Once ready, ask questions about the video content and get AI-powered answers grounded in the transcript.
